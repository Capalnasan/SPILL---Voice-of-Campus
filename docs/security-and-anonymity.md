# Security and Anonymity

## Anonymity Model

Users are anonymous inside the platform, but their real identity is stored securely for serious situations.

## Three-Key Reveal Mechanism

- Three different responsible people each hold an approval role.
- Identity reveal requires all three approvals.
- A clear reason must be provided.
- Every action is written to the audit log.
- Revealed identities should be visible only to authorized roles.

## Security Goals

- Protect user identity by default.
- Prevent abuse of anonymity.
- Keep moderation decisions traceable.
- Make identity reveal rare, justified, and accountable.
