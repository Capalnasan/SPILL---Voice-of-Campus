# Architecture Notes

## High-Level Flow

1. User logs in with university credentials.
2. Backend verifies that the user belongs to UPT.
3. The app creates or loads an anonymous identity for app usage.
4. User writes a post.
5. AI checks relevance, clarity, toxicity, and category.
6. Accepted posts appear in the feed.
7. Sensitive posts can enter manual review.
8. Weekly and monthly reports summarize anonymous, structured feedback.
