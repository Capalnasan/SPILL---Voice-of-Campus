# Spill Mobile

React Native mobile application for the Spill platform.

## Planned Areas

- University login
- Anonymous issue submission flow
- Real-time AI feedback while writing
- Campus issue feed
- Notifications for moderation or report status
- Profile/settings screen without exposing public identity

## Suggested Setup

Initialize this folder with React Native or Expo. For a faster thesis prototype, Expo is usually the smoothest path:

```bash
npx create-expo-app apps/mobile --template
```
