# Spill API

Backend API for authentication, anonymous posting, moderation, reporting, and controlled identity reveal.

## Planned Modules

- Auth module for UPT credential verification
- Users module for private identity records
- Anonymous profiles module for app-facing identities
- Posts module for issue submission and feed
- AI moderation module for relevance, clarity, toxicity, categorization, and summaries
- Reports module for weekly and monthly reports
- Reveal requests module for the three-key identity reveal process
- Audit logs module for accountability

## Suggested Setup

Initialize this folder with NestJS:

```bash
npx @nestjs/cli new apps/api
```
