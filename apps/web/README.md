# Spill Web

React web application for the Spill platform.

## Planned Areas

- Authentication with university credentials
- Anonymous issue submission
- AI-assisted post review and rewrite suggestions
- Moderated issue feed
- Reports dashboard for committee users
- Three-key identity reveal approval UI

## Suggested Setup

Initialize this folder with a React toolchain such as Vite:

```bash
npm create vite@latest apps/web -- --template react-ts
```
